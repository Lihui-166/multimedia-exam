# 软考中级：多媒体应用设计师刷题备考系统

这是一个面向个人备考的纯网页版工具，不需要登录、后端服务或数据库。打开 `index.html` 即可使用。

## 已包含功能

- 学习总览：刷题量、正确率、连续学习和模块掌握度
- 章节专项：多媒体基础、音视频技术、图形图像与动画、交互设计
- 历年/整套模拟入口：先选择整套试卷，再统一答题和交卷
- 全真答题流程：计时、上一题、下一题、交卷评分、45 分合格参考
- 计算机专业英语专项：英文题自动判分
- 错题本：错题重做、标记错题、连续答对 2 次自动移除
- 题目收藏：本地收藏和取消收藏
- 学习统计：累计作答、正确率、章节表现
- 本地资料管理：导出/导入 JSON 数据，记录个人备考笔记
- 近 10 年真题目录：按 2016—2025 年列出上午基础知识、下午应用技术及公开来源链接
- 原创案例模拟卷：4 套下午案例整卷，含案例背景、分问、参考答案、答题保存和自评得分

## 使用方式

直接双击 `index.html`，或在当前目录启动任意静态文件服务器：

```powershell
python -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/index.html`。

## 数据说明

所有错题、收藏、统计和笔记默认保存在当前浏览器的 `localStorage` 中。更换浏览器或清理站点数据前，请在“题库管理”中导出 JSON 备份。

当前版本采用本地单用户架构，因此不包含登录、账号、MySQL 或远程后台。后续如果需要多人账号、云同步或正式题库管理，再拆分 API 服务和数据库即可。

## 题库范围与来源

题库章节按公开考试大纲和公开题库目录扩展，覆盖多媒体技术基础、信息处理、信息传输、移动多媒体、显示发布与搜索、数字版权管理、压缩编码、新技术、信息安全、法律法规、专业英语、策划设计、素材集成和系统实现等方向。

参考资料：

- [清华大学出版社：多媒体应用设计师考试大纲](https://www.tup.tsinghua.edu.cn/upload/books/yz/075352-01.pdf)
- [软题库：多媒体应用设计师章节与历年试卷目录](https://www.ruantiku.com/course/36.html)
- [软考真题目录：多媒体应用设计师历年综合知识与案例](https://www.lightsoft.tech/doquestion/subject?doType=0&index=0&subjectId=abcceba6ca424b22afc7cf73c6bee3b1)
- [希赛网：多媒体应用设计师真题与练习目录](https://www.educity.cn/rk/dmt/index.html)
- [希赛网资料库：公开试卷与案例资料](https://wangxiao.xisaiwang.com/rk/xxzl/n111799.html)
- [51CTO：多媒体应用设计师历年题库目录](https://t.51cto.com/list/years/sub-696)

“历年真题与原创案例”页面中的真题目录只保存公开来源链接，不在本地复制第三方完整题库；打开链接后按年份选择对应上午或下午试卷，部分在线题库可能需要登录。2020、2021 年还提供了公开的下午案例解析入口。

原创案例模拟卷为本项目自行编写，按下午应用技术的案例分析形式组织，覆盖策划设计、素材制作与集成、系统实现、应用场景、安全与测试等考点。作答文字、自评得分保存在当前浏览器本地。

网页内新增的扩充题为依据上述公开知识范围编写的原创练习题，不直接复制第三方题库的整套题干、答案或解析。真实历年试卷建议通过原题库页面在线练习，或在确认授权后再导入个人题库。
